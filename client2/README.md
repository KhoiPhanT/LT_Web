# Giao diện Next.js của đồ án

Giao diện chỉ gồm cổng công khai, đăng nhập OTP/nhân viên, tiếp nhận lệnh, kỹ thuật viên, quản lý kho/báo cáo và thanh toán VietQR. API `/api/v1/*` được Next.js chuyển tới Tomcat Servlet theo `INTERNAL_BACKEND_URL` trong `next.config.mjs`.

Từ thư mục gốc dự án, chạy `./start_backend.sh` rồi `./start_client.sh`. Hướng dẫn và tài khoản mẫu nằm trong `../HUONG_DAN_CHAY_THUC_TE.md` và `../TAI_KHOAN_TEST.md`.
